买新衣服 · AI 尺码建议

把新商品的尺码表粘贴进来，AI 会拿你衣柜里同分类已合身单品的实测数据逐项对照，告诉你买哪个码。国外站点的尺码表如果是英寸（inch），AI 会先换算成厘米再对照，并在建议里注明原单位与换算。

鞋码换算：按脚长查 US / EU / UK / JP 对照

对照以脚长为准，各品牌鞋楦略有差异，同一脚长在不同品牌间常差半码，最终以品牌官方尺码表为准。

今日穿搭 · AI 搭配

根据今天的天气和行程，从你的衣柜里搭一套。天气来源可在下方「天气设置」里切换（默认 Open-Meteo，免费、无需 Key；也可配彩云、OpenWeatherMap、和风天气的 Key）。城市留空时优先用浏览器定位（需授权，被拒或超时会提示你手动输入城市）；定位不到就手动填城市名；还查不到就勾选「手动输入天气」。

今日行程（可选，让搭配更贴合安排）

Google 日历（可选，只读）

在 Google Cloud Console 建一个 OAuth 客户端（Web 应用类型），把 Client ID 填进来，点「连接 Google 日历」授权；应用只读你今天的日程。详细步骤见 README「日历与行程」一节。注意：需页面跑在 http(s) 上（如 GitHub Pages），直接用 file:// 打开时授权回调无效。

Outlook 日历（可选，只读，Microsoft Graph）

在 Azure 门户注册一个应用（平台选“单一页面应用程序”），把应用（客户端）ID 填进来，点「连接 Outlook」授权；应用只读你今天的日程与未来行程。详细步骤见 README「日历与行程」一节。注意：需页面跑在 http(s) 上（如 GitHub Pages），直接用 file:// 打开时授权回调无效。

出差 / 旅行 · 行李与穿搭

填一次出行，按目的地天气和当地安排，给出每天穿搭 + 行李清单。行程也可从日历里自动识别（多日事件 + 地点）。目的地天气按出发城市以外的目的地城市查。

从订票信息生成行程：粘贴文字 / 航班号 / 截图（不用手动填）

航班查询用 AviationStack（aviationstack.com，免费档每月 100 次）。注意：免费档只支持 HTTP，从 HTTPS 页面（GitHub Pages）访问会被浏览器拦截；本地用 http://localhost 打开可用，或改粘贴文字 / 截图识别。

截图识别需要支持图片（vision）的 AI 模型，如 GPT-4o、Gemini；模型不支持时会明确提示，改粘贴文字即可。图片只在浏览器本地处理后发给已配置的 AI 服务商，不进仓库。

邮箱找订票确认

接 Gmail 或 Outlook 邮箱（只读），按关键词搜订票确认邮件，勾选后由 AI 提取行程。不想接邮箱时，直接用上方「粘贴订票文字」或「截图识别」代替。邮件内容只在浏览器本地处理，不上传、不进仓库；不改、不删任何邮件。支持国内外平台：携程、飞猪、12306、Skyscanner、Expedia、Kayak、Google Flights、Trip.com、CheapOair、Booking.com、Agoda、Hotels.com、Airbnb、Hostelworld、Trainline、Amtrak、Eurail、Deutsche Bahn、MakeMyTrip 等。

Gmail（只读）

在 Google Cloud Console 建一个 OAuth 客户端（Web 应用类型），把 Client ID 填进来，点「连接 Gmail」授权只读邮件权限（gmail.readonly）。详细步骤见 README「邮箱找订票确认」一节。注意：需页面跑在 http(s) 上，直接用 file:// 打开时授权回调无效。

Outlook 邮箱（只读，Microsoft Graph，与 Outlook 日历共用授权）

用上面「Outlook 日历」里同一个应用（客户端）ID 即可（权限需包含 Mail.Read）；点「连接 Outlook」授权后，在这里搜邮件。详细步骤见 README「邮箱找订票确认」一节。

天气设置

每日穿搭和出差预报的天气来源。默认用 Open-Meteo（免费、无需 Key）。选其他源需要填自己的 Key，Key 只存浏览器 localStorage。回退链：所选源未配 Key 或请求失败 → 自动回退到 Open-Meteo；城市留空时优先用浏览器定位（需授权，被拒或超时会提示你手动输入城市）；还查不到就勾选「手动输入天气」。

AI 设置

尺码建议、每日穿搭、AI 辅助录入都要走这里配置的 AI。支持任何 OpenAI 兼容接口：填自己的 Key 就行；也可以选 Muse（Meta Model API）。Key 只存在你浏览器的 localStorage 里，不会上传到任何地方，更不会进仓库。

提醒：Muse 的 Key 去 dev.meta.ai 申请（Meta Model API，模型 muse-spark-1.3）。Key 开通可能有地区与审核要求，以官方页面为准；若暂无 Key，先用 DeepSeek 等其他兼容接口即可，功能完全一样。
Anthropic Claude 官方 API 不是 OpenAI 兼容格式，不能直连本应用；如需用 Claude，请经支持 OpenAI 兼容格式的中转服务，再选「自定义 OpenAI 兼容接口」填中转地址。
