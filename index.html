买新衣服 · AI 尺码建议

把新商品的尺码表粘贴进来，AI 会拿你衣柜里同分类已合身单品的实测数据逐项对照，告诉你买哪个码。国外站点的尺码表如果是英寸（inch），AI 会先换算成厘米再对照，并在建议里注明原单位与换算。

鞋码换算：按脚长查 US / EU / UK / JP 对照

对照以脚长为准，各品牌鞋楦略有差异，同一脚长在不同品牌间常差半码，最终以品牌官方尺码表为准。

今日穿搭 · AI 搭配

根据今天的天气和行程，从你的衣柜里搭一套。天气默认用 Open-Meteo（免费、无需 Key）；查不到时可手动输入。

今日行程（可选，让搭配更贴合安排）

Google 日历（可选，只读）

在 Google Cloud Console 建一个 OAuth 客户端（Web 应用类型），把 Client ID 填进来，点「连接 Google 日历」授权；应用只读你今天的日程。详细步骤见 README「日历与行程」一节。注意：需页面跑在 http(s) 上（如 GitHub Pages），直接用 file:// 打开时授权回调无效。

出差 / 旅行 · 行李与穿搭

填一次出行，按目的地天气和当地安排，给出每天穿搭 + 行李清单。行程也可从日历里自动识别（多日事件 + 地点）。目的地天气按出发城市以外的目的地城市查。

AI 设置

尺码建议、每日穿搭、AI 辅助录入都要走这里配置的 AI。支持任何 OpenAI 兼容接口：填自己的 Key 就行；也可以选 Muse（Meta Model API）。Key 只存在你浏览器的 localStorage 里，不会上传到任何地方，更不会进仓库。

提醒：Muse 的 Key 去 dev.meta.ai 申请（Meta Model API，模型 muse-spark-1.3）。Key 开通可能有地区与审核要求，以官方页面为准；若暂无 Key，先用 DeepSeek 等其他兼容接口即可，功能完全一样。
Anthropic Claude 官方 API 不是 OpenAI 兼容格式，不能直连本应用；如需用 Claude，请经支持 OpenAI 兼容格式的中转服务，再选「自定义 OpenAI 兼容接口」填中转地址。
